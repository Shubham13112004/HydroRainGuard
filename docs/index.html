HYDRO RAIN GUARD - report paste pack

Every file below holds the same report text, figures and tables in a form you can copy straight into Word.

Open the full report →

To paste into Word: open full_report.html (or a single chapter), press Ctrl+A then Ctrl+C, and paste into Word with Keep Source Formatting. Headings, justified 12 pt Times New Roman text, real tables and all pictures come across. Then set A4 with top 23.4 mm, left 37 mm, bottom 32 mm, right 23.4 mm and add the footer.
