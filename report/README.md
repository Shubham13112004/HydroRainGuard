# BE Project Work - II report

The main deliverable is:

- `HydroRainGuard_BE_Project_Stage_II_Report.docx`

It follows the attached Stage-II report template: A4 page setup, Times New Roman
12 pt justified body text with 1.5 line spacing, five-space first-line
indentation, 14 pt centred chapter titles, 12 pt numbered section headings,
10 pt centred footer, black-and-white figures, figure titles and legends below
each illustration, Roman page numbers for preliminary pages and Arabic page
numbers starting at the Introduction.

The numbered main report has 78 pages from Chapter 1 through Appendix F.
Chapters 1-11 alone occupy pages 1-71, so the report stays inside the
institute's 70-80 page limit even if appendices are excluded. The three
reference/bibliography pages follow as pages 79-81 and are excluded from the
limit. Page numbers are Word fields; press `Ctrl+A` then `F9` in Microsoft Word
after any editing to refresh them.

## Regeneration

From the repository root:

```bash
.venv/bin/python report/generate_evidence.py
.venv/bin/python report/build_report.py
```

`generate_evidence.py` runs the real FastAPI assessment pipeline, writes
`data/scenarios.json` and `data/sample_report.pdf`, and builds every chart,
diagram and processed screenshot in `figures/`. `build_report.py` assembles the
DOCX from `report_content.py`. The original colour UI captures are kept in
`figures_raw/`; the DOCX uses the grayscale versions in `figures/`.
