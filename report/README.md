# BE Project Work - II report

The main deliverable is:

- `HydroRainGuard_BE_Project_Stage_II_Report.docx`

It follows the attached Stage-II report template: A4 page setup, Times New Roman
12 pt justified body text with 1.5 line spacing, five-space first-line
indentation, 14 pt centred chapter titles, 12 pt numbered section headings,
10 pt centred footer, black-and-white figures, figure titles and legends below
each illustration, Roman page numbers for preliminary pages and Arabic page
numbers starting at the Introduction.

The numbered main report has 78 pages from Chapter 1 through Appendix F.
Chapters 1-11 alone occupy pages 1-71, so the report stays inside the
institute's 70-80 page limit even if appendices are excluded. The three
reference/bibliography pages follow as pages 79-81 and are excluded from the
limit. Page numbers are Word fields; press `Ctrl+A` then `F9` in Microsoft Word
after any editing to refresh them.

## Copy-paste pack (text + figures + tables)

`report/direct/` holds the same report as material that can be pasted into Word
by hand:

- `direct/index.html` - landing page with a link to every chapter and the
  sample outputs.
- `direct/full_report.html` - the complete report on one page (also prints to
  PDF cleanly).
- `direct/00_Cover.html`, `direct/Ch01_Introduction.html` ...
  `direct/12_References.html` - one file per chapter / appendix / front-matter
  page, so chapters can be pasted one at a time.
- `direct/images/` - all 53 figures as `Fig_<chapter>.<n>_<title>.png`.
- `direct/full_report.md` - plain Markdown mirror of the whole text.
- `direct/sample_outputs/` - `sample_report.pdf`, `scenarios.json` and
  `ui_assessment.json` reproduced in the appendices and results chapter.
- `direct/hydrorainguard_report_pack.zip` - everything above in one download.

Open the HTML in a browser, press `Ctrl+A` then `Ctrl+C`, and paste into Word
with *Keep Source Formatting*: chapter titles, justified 12 pt Times New Roman
text, real bordered tables and inline pictures come across. Then set A4 with the
four template margins and add the footer.

The pack is generated from the built DOCX:

```bash
.venv/bin/python report/build_report.py      # rebuild the DOCX first
.venv/bin/python report/build_direct.py      # write report/direct/
python -m http.server 8000 --directory report/direct   # optional preview
```

`direct/images/`, `direct/sample_outputs/` and the zip are generated and
git-ignored; `build_direct.py` recreates them.

## Regeneration

From the repository root:

```bash
.venv/bin/python report/generate_evidence.py
.venv/bin/python report/build_report.py
```

`generate_evidence.py` runs the real FastAPI assessment pipeline, writes
`data/scenarios.json` and `data/sample_report.pdf`, and builds every chart,
diagram and processed screenshot in `figures/`. `build_report.py` assembles the
DOCX from `report_content.py`. The original colour UI captures are kept in
`figures_raw/`; the DOCX uses the grayscale versions in `figures/`.

## Google Docs version

An editable Google Docs copy of the same report (same chapter order, headings,
figures with captions and legends, tables and references) is available at:

`https://docs.google.com/document/d/1PEec2q-1G31iq0cFL8lF5-Q1O1USmQ_ku3BDceh9tJc/edit`

Notes for the Google Docs copy:

- A4 page size and template margins (top 23.4 mm, left 37 mm, bottom 32 mm,
  right 23.4 mm) are applied to the document style; body text is Times New
  Roman 12 pt, justified, 1.5 line spacing with a 36 pt first-line indent.
- The cover page, certificate, acknowledgement, abstract, TOC, lists,
  11 chapters, 6 appendices and references are all present, in the template
  order, with centred 14 pt bold capitals for chapter/appendix titles and
  page breaks before each one.
- All 53 figures are inserted with their 12 pt caption and 10 pt legend.
- Table content is carried as pipe-delimited rows at 9 pt (see the limitation
  below); the DOCX has the same tables as true Word tables.
- The footer "RSCOE, Department of Information Technology 2026-27" is already
  in place, centred, 10 pt Times New Roman. Live page-number fields cannot be
  created through the Docs connector, so add them from the UI with
  `Insert > Page numbers > Bottom of page`. Google Docs numbers a document as
  a single sequence, so the Roman (i-xi) to Arabic (1-81) switch used in the
  DOCX is not reproducible there; use the DOCX/PDF for the numbered print copy.
- TOC and list-of-figures page numbers are the print estimates from the DOCX
  build; update them after the final pagination.

Known Google Docs limitations (both come from the connector, not the report):

- Tables cannot be inserted in bulk cheaply, so each table block is a set of
  `A | B | C` paragraphs. To convert one: select its rows, then
  `Format > Convert > Text to table`, separator "Other" = `|`.
- For a print-exact Google Doc with native tables and live page numbers, upload
  `report/HydroRainGuard_BE_Project_Stage_II_Report.docx` to Drive and open it
  with Google Docs (Drive converts it, keeping tables, footers and figures).

`google_docs_export.py` regenerates the plain-text stream used to build the
Google Docs copy.
