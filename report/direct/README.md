# Report paste pack

Generated from `report/HydroRainGuard_BE_Project_Stage_II_Report.docx`.

## Fastest route into Word

1. Open `index.html` in a browser (or the live preview) and click the chapter you need.
2. Select all (`Ctrl+A`), copy (`Ctrl+C`).
3. In Word paste with *Keep Source Formatting*.

Chapter titles, 12 pt Times New Roman body text (justified, 1.5 spacing, 36 pt first-line
indent), captions, legends and real bordered tables are reproduced. Pictures paste inline.

## Page setup in Word

- A4, margins: top 23.4 mm, left 37 mm, bottom 32 mm, right 23.4 mm.
- Footer: `RSCOE, Department of Information Technology 2026-27`, then
  Insert > Page Number > Bottom of Page.
- Chapter titles already carry a page break before them.
